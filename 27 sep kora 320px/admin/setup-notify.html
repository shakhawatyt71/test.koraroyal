Notification Setup

Cloudflare Worker + D1 + Web Push. No Firebase account needed. Do these 4 steps once — takes about 5 minutes.

1

Generate your VAPID keys

These keys let your Worker send push notifications. They are created inside your browser and never leave this page.

2

Add them to your Worker secrets

Do this only once. If you generate new keys later, every already-subscribed phone will stop receiving notifications.
  1. Cloudflare Dashboard → Workers & Pages → your worker (kora-api)
  2. Tab Settings → Variables and Secrets
  3. Click Add, type = Secret, name = VAPID_PUBLIC_KEY, value = paste the public key → Save
  4. Click Add again, type = Secret, name = VAPID_PRIVATE_KEY, value = paste the private key → Save
  5. Optional but recommended: name = VAPID_SUBJECT, type = Text, value = mailto:your-email@example.com
  6. Click Deploy if Cloudflare asks
3

Create the notification tables

Creates push_subscriptions, notifications, notification_deliveries, notification_inbox and notification_votes in your D1 database. Safe to run again — it never deletes data.

4

Turn on the schedule (cron trigger)

This is what makes daily, weekly and scheduled notifications actually fire. Without it only “Send now” works.

In the Cloudflare dashboard: your worker → Settings → Triggers → Cron Triggers → Add Trigger → type * * * * * → Save. That means “run every minute”.
