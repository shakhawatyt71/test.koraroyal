Integration
Live credentials (Cloudflare Worker → Settings → Variables and Secrets)

Pathao Merchant Panel → Developer API → copy Client ID and Client Secret → add as Worker secrets PATHAO_CLIENT_ID and PATHAO_CLIENT_SECRET. That is all the API needs (same login flow as Pathao's official WooCommerce plugin). PATHAO_USERNAME / PATHAO_PASSWORD are optional legacy fallbacks.
