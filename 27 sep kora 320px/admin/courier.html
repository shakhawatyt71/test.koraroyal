৬ · Special Instructions

পাঠাওর ফর্মে "Special Instructions"। এখানে যা লিখবেন প্রতিটা পার্সেলে তাই যাবে।

৭ · Auto Booking
⚠ worker.js এখনো ঠিক করা হয়নি। worker-এর autoBookPathao-তে ভুল হার্ডকোড cityId ম্যাপ আর প্রি-পেইড ডাবল-কালেকশন বাগ আছে। Worker patch না লাগানো পর্যন্ত এটা অফ রাখুন — Orders পেজ থেকে ম্যানুয়ালি পাঠান (সেটা এখন ঠিক আছে)।

✅ পিকআপ রিকোয়েস্ট কখনোই অটো হবে না। পাঠাওর API-তে পিকআপ রিকোয়েস্টের কোনো এন্ডপয়েন্টই নেই — আপনাকে পাঠাওর প্যানেল থেকে ম্যানুয়ালি দিতে হবে।

৮ · Delivery Area (City / Zone / Area)

১০ · Webhook
পাঠাওর চেকলিস্ট (আপনার স্ক্রিনশট থেকে):
✅ URL reachable · ✅ ≤3 redirects · ✅ valid SSL · ✅ responds <10s
❌ must return status 202 · ❌ must return header X-Pathao-Merchant-Webhook-Integration-Secret · ❌ value must be exactly the Pathao UUID

সমাধান: Cloudflare → Worker → Settings → Variables and Secrets-এ PATHAO_WEBHOOK_INTEGRATION_SECRET = পাঠাওর UUID বসান, তারপর worker patch (ধাপ ৪) লাগান।
